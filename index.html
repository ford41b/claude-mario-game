FROZEN — press P to resume

Controls

Move←→ or AD
Crouch / pipe↓ or S
Climb↑↓ or WS
Jump / swim (A)X K Space
Run / fire (B)Z J
Start / pauseEnter
SelectRight Shift Tab

Gamepad

D-pad or left stick. Bottom/right face button = A, left/top = B, Start, Select.

Other keys

FreezeP
ResetF2
MuteM
FullscreenF

Title screen: Select picks 1 or 2 players. After a game over, hold A and press Start to continue from the current world.

Original graphics & music

This project ships redrawn graphics and no music. If you own the cartridge, load its ROM file (.nes) to use the original graphics and music. The file stays in this browser.
